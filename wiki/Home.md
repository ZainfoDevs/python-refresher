# Python Refresher

Welcome!

The Python Refresher helps you learn or revisit Python through clear explanations, practical examples, exercises, and small projects.

You will begin with the fundamentals and gradually move into data processing, object-oriented programming, error handling, and other concepts that prepare you to build Python APIs.

You do not need previous programming experience. Each guide introduces the concept, explains why it matters, and gives you opportunities to apply what you learn.


***

## Course Structure

The course follows a progressive structure. Each section builds on the knowledge and skills you developed in the previous sections.

| Section | Focus |
| --- | --- |
| 1. Introduction | Install Python, set up your development environment, and run your first program. |
| 2. Python Fundamentals | Work with data types, functions, conditionals, user input, and loops. |
| 3. Intermediate Python | Use list comprehensions, function arguments, and file-processing techniques. |
| 4. Advanced Python | Organize and reuse code with modules, packages, and third-party libraries. |
| 5. Working with Data | Use pandas and Jupyter Notebook to load, explore, filter, and update structured data. |
| 6. OOP Basics for Python APIs | Work with classes, exceptions, type hints, first-class functions, and decorators. |

Use the table of contents below or the Wiki sidebar to navigate the course.

## What You Will Learn

By working through this course, you will learn how to:

- write and run Python programs
- choose and work with appropriate data types
- control program flow with conditionals and loops
- organize reusable code with functions, modules, and packages
- read, write, and process files
- load and explore structured data with pandas
- build programs with classes and objects
- handle errors with built-in and custom exceptions
- use first-class functions and decorators
- translate real-world requirements into working Python programs

The course does more than show you what to type. It explains why the code works, what happens when it runs, and how each concept fits into a complete program.

Practical scenarios—including a sentence maker, data-processing exercises, and a solar monitoring application—help you connect Python syntax to real problems.


***

## Who This Course Is For

This course supports:

- beginners who want to learn Python step by step
- returning learners who want to refresh their Python knowledge
- technical writers who want to understand the code they document
- developers who want clear explanations of core Python concepts

You do not need previous programming experience. Curiosity, practice, and a willingness to experiment will help you get the most from the course.


***

## How to Get the Most from This Course

### Write the Code

Type the examples on your computer and run them. Writing the code yourself will help you become familiar with Python syntax and understand how each statement affects the program.

### Experiment with the Examples

Change the values, modify the conditions, and observe the results. Experimenting with the code will help you understand how and why its behavior changes.

### Extend the Programs

Add features, try a different approach, or adapt an example to solve another problem. These small changes will help you develop confidence and independence.

### Learn from Errors

Errors are part of programming. Read the error message, identify what caused the problem, and test a possible solution. Each error gives you an opportunity to understand Python more deeply.

### Ask Questions

No programmer learns everything alone. Use documentation, developer communities, and discussions with other learners to explore unfamiliar concepts and solve problems.
