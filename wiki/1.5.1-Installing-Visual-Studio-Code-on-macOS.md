# Installing Visual Studio Code on macOS

Install Visual Studio Code (VS Code) on your Mac and open a folder for your Python projects.

After you complete this guide, you will be ready to install the Python extension.


***

## Before You Begin

Install and verify Python before you begin. For instructions, see [Installing Python](1.4-Installing-Python).


***

## Install Visual Studio Code

1. Open your browser and go to the [Visual Studio Code website](https://code.visualstudio.com/).

2. Select **Download for macOS**.

<p align="center">
  <img
    src="https://raw.githubusercontent.com/ZainfoDevs/python-refresher/main/vscode_macOS.png"
    alt="Visual Studio Code download page showing the Download for macOS button"
  >
</p>

> **Note:** The download page detects your Mac's processor, so the filename may differ from the one shown. Macs with Apple silicon download an `arm64` build, and Intel Macs download an `x64` build.

3. After the download finishes, open the downloaded `.dmg` file.

<p align="center">
  <img
    src="https://raw.githubusercontent.com/ZainfoDevs/python-refresher/main/vscode_macOS1.0.png"
    alt="Finder showing the downloaded VSCode-darwin-arm64.dmg file"
  >
</p>

4. Drag **Visual Studio Code** into the **Applications** folder.

<p align="center">
  <img
    src="https://raw.githubusercontent.com/ZainfoDevs/python-refresher/main/vscode_macOS1.1.png"
    alt="Visual Studio Code disk image showing the Visual Studio Code and Applications icons"
  >
</p>

5. Eject the disk image, then move the downloaded `.dmg` file to the Trash.

6. Open the **Applications** folder and double-click **Visual Studio Code**.

<p align="center">
  <img
    src="https://raw.githubusercontent.com/ZainfoDevs/python-refresher/main/vscode_macOS1.2.png"
    alt="Finder showing Visual Studio Code in the Applications folder"
  >
</p>

> **Note:** If macOS displays a security message, select **Open** to continue.

<p align="center">
  <img
    src="https://raw.githubusercontent.com/ZainfoDevs/python-refresher/main/vscode_macOS1.3.png"
    alt="macOS security message asking whether to open Visual Studio Code"
  >
</p>

VS Code opens on your Mac.

<p align="center">
  <img
    src="https://raw.githubusercontent.com/ZainfoDevs/python-refresher/main/vscode_macOS1.4.png"
    alt="Visual Studio Code welcome screen on macOS"
  >
</p>


***

## Create a Project Folder

Create a folder to store the Python files you will use throughout this refresher.

1. Open **Finder**.

2. Select **Documents** in the Finder sidebar, or open another location where you want to store your projects.

<p align="center">
  <img
    src="https://raw.githubusercontent.com/ZainfoDevs/python-refresher/main/vscode_macOS1.5.png"
    alt="Finder showing the Documents folder selected in the sidebar"
  >
</p>

3. Select **File** > **New Folder**.

4. Name the folder:

```text
solar_monitoring_project
```

<p align="center">
  <img
    src="https://raw.githubusercontent.com/ZainfoDevs/python-refresher/main/vscode_macOS1.6.png"
    alt="Finder showing the solar_monitoring_project folder in Documents"
  >
</p>

This folder will store the Python files for your first project.


***

## Open the Project Folder in VS Code

1. In VS Code, select **File** > **Open Folder**.

<p align="center">
  <img
    src="https://raw.githubusercontent.com/ZainfoDevs/python-refresher/main/vscode_macOS1.7.png"
    alt="Visual Studio Code File menu showing the Open Folder option"
  >
</p>

2. Select the `solar_monitoring_project` folder.

<p align="center">
  <img
    src="https://raw.githubusercontent.com/ZainfoDevs/python-refresher/main/vscode_macOS1.8.png"
    alt="macOS Open dialog showing the solar_monitoring_project folder"
  >
</p>

3. Select **Open**.

4. If VS Code asks whether you trust the authors of the files in the folder, select **Trust**.

<p align="center">
  <img
    src="https://raw.githubusercontent.com/ZainfoDevs/python-refresher/main/vscode_macOS1.9.png"
    alt="Visual Studio Code Workspace Trust dialog listing the features enabled in a trusted folder, with the Trust button highlighted"
  >
</p>

> **Note:** Only trust a folder when you created it yourself or obtained its files from a source you trust.

VS Code confirms that you trust the folder and enables all features.

<p align="center">
  <img
    src="https://raw.githubusercontent.com/ZainfoDevs/python-refresher/main/vscode_macOS1.10.png"
    alt="Visual Studio Code Workspace Trust panel confirming that you trust the folder and that all features are enabled"
  >
</p>

VS Code opens the folder and displays it in the Explorer.

<p align="center">
  <img
    src="https://raw.githubusercontent.com/ZainfoDevs/python-refresher/main/vscode_macOS1.11.png"
    alt="Visual Studio Code Explorer showing the solar_monitoring_project folder"
  >
</p>


***

## Installation Complete

Visual Studio Code is installed, and your project folder is open.
